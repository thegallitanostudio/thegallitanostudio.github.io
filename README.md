# thegallitanostudio.com

The live site for The Gallitano Studio, served by GitHub Pages from this repository.
Every change to the main branch goes live in about a minute.

## The one file to edit

`config.js` holds the booking link and the contact email. Change a value, commit, done.

## What's here

Five pages, written by hand: Home (`index.html`), `work-with-me/`, `for-companies/`, `about/` and `book/`.
They share one stylesheet (`css/site.css`) and one small script (`js/site.js`, the phone menu and the
Referred form). Photos and logos live in `assets/`, fonts in `fonts/` (Fraunces and Outfit, SIL Open Font
License, licenses included).

The old paths (`products/`, `programs/`, `corporate/`, `founder/`, `referred/`, `accelerator/`, `live/`,
`five-prompts/`) are redirect pages that send visitors to the right new page. Keep them so old links still work.

To change copy, edit the page's `index.html` directly, or ask Claude for updated files and upload them here.
