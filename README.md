# thegallitanostudio.com

The live site for The Gallitano Studio, served by GitHub Pages from this repository.
Every change to the main branch goes live in about a minute.

## The one file to edit

`config.js` holds the booking link and the contact email. Change a value, commit, done.

## What's here

Twelve pages, written by hand: Home (`index.html`), `work-with-me/` (with `first-look/`, `executive/` and
`accelerator/`), `for-companies/` (with `business-case/`), `executiveos/`, `about/`, `questions/`, `contact/`
and `book/`. Five one-page fact sheets are in `fact-sheets/`.

Styles are in `css/` and load in a fixed order on every page; new work goes in a new file loaded last
(before `motion.css`), and the older files are not edited. Scripts are in `js/`. Photos are in `assets/`,
fonts in `fonts/` (Instrument Sans, SIL Open Font License, license included).

The old paths (`products/`, `programs/`, `corporate/`, `founder/`, `referred/`, `accelerator/`, `live/`)
are redirect pages that send visitors to the right new page. Keep them so old links still work.
